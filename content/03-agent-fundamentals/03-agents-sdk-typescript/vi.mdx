## Mục tiêu học tập

Nêu các đối tượng agent/tool/handoff; chọn khi nào SDK đơn giản hơn orchestration tự viết.

## Điều kiện tiên quyết

Hoàn thành bài liên quan trước đó: [tool-calling](/learn/tool-calling). Nếu đã biết phần này, hãy dùng câu hỏi thực hành để tự đánh giá.

## Lý thuyết

Trong Agents SDK, **agent** là đơn vị workflow kết hợp model và instructions, cùng các hành vi runtime tùy chọn như tools, guardrails, MCP servers, handoffs và structured outputs. Agents SDK cung cấp abstraction cho agent loop, tool, handoff và tracing. Dùng SDK khi các tính năng này giải quyết nhu cầu thật; vẫn cần hiểu vòng lặp và giới hạn. Đặt instructions, tool contracts và output validation cạnh agent definition để dễ review. [OpenAI: Agent definitions](https://developers.openai.com/api/docs/guides/agents/define-agents)

## Kiến trúc

Request → triage agent → (handoff có điều kiện) specialist → tool execution có policy → final response và trace.

## Ví dụ TypeScript

```ts
const supportAgent = new Agent({
  name: "Support",
  instructions: "Answer from approved support sources.",
  tools: [lookupOrder],
});
```

Đây là đoạn minh họa ranh giới/kiểu dữ liệu; trước production cần bổ sung validation, error handling và quyền phù hợp với use case.

## Thực hành

Xây sơ đồ agent hỗ trợ chỉ có một tool read-only; thêm điều kiện handoff sang người thật khi thiếu dữ kiện hoặc cần sửa giao dịch.

## Lỗi thường gặp

Thêm nhiều agent dù một agent đủ; để handoff làm mất context cần thiết; coi SDK tracing là kiểm soát bảo mật.

### 1. \* Essential — Agents SDK xử lý những gì quanh model?

**Vì sao cần ưu tiên:** Hiểu vòng lặp runtime giúp phân biệt việc SDK xử lý với trách nhiệm server.

**Gợi ý trả lời:** SDK chạy vòng lặp agent và phối hợp tool cùng hành vi đã cấu hình. Ứng dụng vẫn chịu trách nhiệm triển khai, thông tin xác thực, cài đặt tool, lưu trữ và quyết định cấp quyền.

Nguồn kiểm chứng: [OpenAI Agents SDK](https://developers.openai.com/api/docs/guides/agents/sdk).

### 2. Khi nào chọn handoff thay vì dùng agent như tool?

**Gợi ý trả lời:** Handoff chuyển quyền tiếp tục hội thoại sang chuyên gia. Agent dạng tool trả trợ giúp có phạm vi; manager vẫn chịu trách nhiệm câu trả lời cuối cùng.

Nguồn kiểm chứng: [Orchestration and handoffs](https://developers.openai.com/api/docs/guides/agents/orchestration).

### 3. Input guardrail cấp agent có bảo vệ mọi tool call không?

**Gợi ý trả lời:** Không. Vị trí chạy phụ thuộc ranh giới chuỗi agent. Đặt authorization và kiểm tra tác động ngay quanh tool liên quan; dùng approval interruption cho hành động cần người xét duyệt.

Nguồn kiểm chứng: [Guardrails and human review](https://developers.openai.com/api/docs/guides/agents/guardrails-approvals).
