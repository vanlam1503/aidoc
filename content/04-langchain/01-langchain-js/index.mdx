## Learning objectives

Describe Runnable composition, evaluate abstraction and dependency costs, and separate integrations from domain logic.

## Prerequisites

Complete the prerequisite lesson: [responses-api](/learn/responses-api). If you already know this material, use the practice questions to assess your understanding.

## Theory

LangChain.js provides integrations and composable runnables for prompts, models, parsers, retrievers, and tools. These abstractions help when swapping components or assembling a pipeline; a single simple call may need fewer layers with an official SDK. Track versions because the package ecosystem changes quickly.

## Architecture

Input schema → prompt and runnable → model integration → parser → domain validation; instrument meaningful steps.

## TypeScript example

```ts
const chain = prompt.pipe(model).pipe(new StringOutputParser());
const result = await chain.invoke({ question: "What is retrieval?" });
```

This snippet illustrates boundaries and data types. Before production use, add validation, error handling, and permissions appropriate to the use case.

## Practice

Compare a JSON-output pipeline using an SDK directly with a LangChain implementation. Record layers, testability, dependency surface, and failure points.

## Common mistakes

Adding a framework before establishing the need; leaking framework-specific objects into domain logic; neglecting integration dependency versions.

### 1. \* Essential — When would you use LangChain instead of direct SDK calls?

**Why essential:** Framework choice should follow the control flow the application needs.

**Answer outline:** Use it when shared model/tool abstractions and integrations reduce repeated work. For a small fixed flow, direct SDK calls may be easier to inspect and maintain.

Reference: [LangChain TypeScript overview](https://docs.langchain.com/oss/javascript/langchain/overview).

### 2. When does a workflow need LangGraph?

**Answer outline:** When explicit state, branching, recovery, or human review requires control over execution. Separate deterministic steps from model-selected actions instead of making every step autonomous.

Reference: [LangGraph workflows and agents](https://docs.langchain.com/oss/javascript/langgraph/workflows-agents).

### 3. An integration upgrade changes output behavior. How would you investigate?

**Answer outline:** Pin versions, inspect the affected adapter, and compare representative inputs, parsed outputs, and traces against the baseline. A common interface does not guarantee identical provider behavior.

Reference: [LangChain TypeScript overview](https://docs.langchain.com/oss/javascript/langchain/overview).
