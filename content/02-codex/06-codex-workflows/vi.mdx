## Mục tiêu học tập

Tổ chức workflow review; phân loại finding theo bằng chứng và mức độ; tránh sửa ngoài scope.

## Điều kiện tiên quyết

Hoàn thành bài liên quan trước đó: [agents-md](/learn/agents-md). Nếu đã biết phần này, hãy dùng câu hỏi thực hành để tự đánh giá.

## Lý thuyết

Agent review code nên tìm lỗi có thể dẫn đến hành vi sai, lỗ hổng hoặc regression; mỗi finding cần chỉ vị trí, điều kiện tái hiện và tác động. Reviewer con người xác nhận vì model có thể báo sai hoặc bỏ sót. Workflow sửa lỗi nên giữ reproduction test để ngăn lỗi quay lại.

## Kiến trúc

Diff + requirements + test context → agent findings có severity/evidence → maintainer triage → targeted fix → regression test → review lại.

## Ví dụ TypeScript

```ts
type Finding = { file: string; line: number; impact: string; evidence: string; confidence: number };
function actionable(f: Finding): boolean { return f.evidence.length > 0 && f.impact.length > 0; }
```

Đây là đoạn minh họa ranh giới/kiểu dữ liệu; trước production cần bổ sung validation, error handling và quyền phù hợp với use case.

## Thực hành

Dùng một diff nhỏ, yêu cầu review chỉ tìm correctness/security. Ghi finding, kiểm tra thủ công, thêm test cho một lỗi thật và chạy lại review.

## Lỗi thường gặp

Yêu cầu review toàn repository không nêu phạm vi; chấp nhận finding thiếu evidence; để agent tự merge hoặc deploy.

### 1. \* Essential — Bạn tổ chức workflow sửa bug trong repository thế nào?

**Vì sao cần ưu tiên:** Lỗi tái hiện được là điểm bắt đầu để kiểm chứng bản sửa.

**Gợi ý trả lời:** Tái hiện lỗi, đọc hướng dẫn và mã liên quan, sửa đúng phạm vi, chạy kiểm tra phù hợp và đánh giá diff cuối cùng theo tiêu chí nghiệm thu.

Nguồn kiểm chứng: [Codex testing and review practices](https://learn.chatgpt.com/docs/learn/best-practices).

### 2. Giữ các thay đổi khác của lập trình viên thế nào?

**Gợi ý trả lời:** Kiểm tra trạng thái repository trước khi sửa, giữ patch hẹp và đọc từng hunk. Dùng worktree riêng khi cần; không coi các thay đổi chưa commit là có thể bỏ đi.

Nguồn kiểm chứng: [Codex CLI](https://learn.chatgpt.com/docs/codex/cli).

### 3. Bản bàn giao của agent cần những gì?

**Gợi ý trả lời:** Nêu hành vi sau thay đổi, phạm vi đã sửa, bằng chứng kiểm tra và giới hạn còn lại. Ghi rõ quyết định đang chờ và bước khôi phục để người tiếp theo làm tiếp.
