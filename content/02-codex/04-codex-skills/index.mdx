## Learning objectives

Explain skill discovery, write a suitable description, and decide when scripts or references are needed.

## Prerequisites

Complete the prerequisite lesson: [agents-md](/learn/agents-md). If you already know this material, use the practice questions to assess your understanding.

## Theory

A skill packages a reusable workflow for tasks that match its purpose. Its description should state triggers and boundaries. Detailed instructions load when needed; keep resources and scripts separate so unrelated tasks do not pay the context cost. A skill does not grant hidden permissions or bypass policy.

## Architecture

User request → match skill metadata → load instructions and resources → execute workflow → verify output against skill acceptance criteria.

## TypeScript example

```ts
type SkillManifest = { name: string; description: string; entrypoint: string };
const skill: SkillManifest = { name: "release-notes", description: "Use when preparing a release summary from merged changes", entrypoint: "SKILL.md" };
```

This snippet illustrates boundaries and data types. Before production use, add validation, error handling, and permissions appropriate to the use case.

## Practice

Choose a recurring team workflow. Define triggers and non-triggers, inputs, steps, outputs, and checks. Try both relevant and unrelated requests.

## Common mistakes

Overly broad descriptions that trigger incorrectly; duplicating the entire handbook; untested scripts or hidden side effects.

## Interview questions

Original practice questions based on the primary references below, checked on 2026-11-07. These are preparation exercises, not verified questions from a particular employer. Design answers suggest one defensible approach. The literal \* Essential marker indicates editorial priority; start there before the follow-up questions.

### 1. \* Essential — What does a skill package, and when should it activate?

**Why essential:** Clear activation conditions prevent a reusable workflow from running in the wrong task.

**Answer outline:** A SKILL.md defines its name, description, and workflow, with optional scripts and resources. Its description should identify both useful situations and boundaries.

Reference: [Build skills](https://learn.chatgpt.com/docs/build-skills).

### 2. Why use progressive disclosure for skills?

**Answer outline:** Load brief discovery metadata first, then the selected workflow and necessary references. This limits irrelevant context while retaining detailed guidance when the task needs it.

Reference: [Build skills](https://learn.chatgpt.com/docs/build-skills).

### 3. A skill includes a shell script. What would you review before using it?

**Answer outline:** Inspect the script, inputs, filesystem writes, network access, and secret handling. Reusable instructions do not replace sandbox enforcement or task-specific authorization.

Reference: [Agent approvals and security](https://learn.chatgpt.com/docs/agent-approvals-security).
